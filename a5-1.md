### Test Idea 1: Valid Standard Password

- **Scenario:** Test a password that meets all criteria comfortably.

### Test Idea 2: Minimum Length Boundary (8 Characters)

- **Scenario:** Test the lower boundary of the length requirement.
- **Input:** `P1asswrd` (8 characters, contains uppercase 'P' and digit '1').

### Test Idea 3: Below Minimum Length (7 Characters)

### Test Idea 4: Maximum Length Boundary (20 Characters)
